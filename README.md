# Organizador de estudos

Programa de terminal que registra sessões de estudo e mostra o desempenho.
Serve para qualquer pessoa que estuda: concurso, faculdade, idioma ou programação.

Faz parte da minha [jornada de programação](https://github.com/otahara/jornada-programacao).

## Como usar

python organizador.py

## Versões

| Versão | O que faz |
|---|---|
| v1 | registra uma sessão de estudo e mostra o resumo com tempo e percentual de acertos |
